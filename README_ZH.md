# EchoLoom 可运行交互 Demo

这是一个可以在本地电脑完整体验的移动端产品原型。解压后也可以先打开 `START_HERE_中文.txt` 查看最简启动说明。它不是静态图片，而是包含命运观测站主线、回声终端 EchoLink、五角色关系模拟、异步消息剧情、共享 NPC 决策、分支回溯、分型记忆、世界/NPC 设定卡、导入导出和本地保存的可交互 Demo。

## 30 秒启动

### macOS

1. 安装 Node.js 18 或更新版本。
2. 解压项目。
3. 双击 `run-mac.command`。
4. 浏览器会自动打开 `http://127.0.0.1:5173`。

macOS 第一次阻止脚本时，可以右键文件并选择“打开”，或在终端中运行：

```bash
cd EchoLoom_Interactive_Demo
npm start
```

### Windows

1. 安装 Node.js 18 或更新版本。
2. 解压项目。
3. 双击 `run-windows.bat`。

### 通用方式

```bash
cd EchoLoom_Interactive_Demo
npm start
```

项目没有第三方依赖，因此不需要先执行 `npm install`。

也可以直接双击 `index.html`，但通过本地服务器运行时，PWA 缓存和部分浏览器功能更稳定。

## 可选的真实 API 模式

离线 `EchoEngine` 仍是默认模式，不需要账号、网络或 API Key。若要测试真实闭环：

```bash
cp .env.example .env
# 只填写需要测试的服务端密钥
npm start
```

然后在“设置 → 对话引擎”选择“Gemini 服务端 API”。在线链路为：

```text
玩家输入 → 当前角色上下文与相关记忆 → Gemini 结构化 Game Event
        → 服务端校验与规则确认 → 关系/剧情/记忆更新
        → 仅在 scene.changed 时请求 Cloudflare 背景 → 指纹缓存
```

- Gemini：生成简短角色回复、表情/情绪、关系方向、剧情提议、场景描述、记忆候选和最多三个意图按钮。
- Supabase（可选）：按当前角色隔离保存消息、关系、故事状态和四类长期记忆。先执行 `supabase/migrations/202608100001_api_foundation.sql`，再执行 `supabase/seed.sql`。
- Cloudflare Workers AI（可选）：只为已确认的场景变化生成 FLUX 背景；相同提示词直接读取 `.cache/echoloom-scenes`。
- 任一服务未配置、超时或失败时，会自动使用原有离线角色逻辑或打包背景，不中断故事。

所有真实密钥只放在被 Git 忽略的 `.env`；浏览器代码不会收到 Gemini、Supabase service role 或 Cloudflare token。完整配置、接口和数据库初始化步骤见 `docs/OPTIONAL_REAL_AI_UPGRADE.md`。

## 建议的完整体验路径

1. 17 秒停电：点击“回应求救信号”。
2. 五处信号：先回应祁安、沈曜、黎川、周棠或闻笙。第一次选择只决定相遇顺序，并写入一条线索及跨角色影响。
3. 首次响应：自由输入或选择行动意图；过早示爱或身体亲密会得到符合角色边界的回应。
4. 命运观测站：依次认识另外四人，解锁共享 NPC“绥”的事件。
5. 回声终端：从观测站进入 EchoLink 锁屏，查看讯息、联系人、动态、关系和档案五页。
6. 异步剧情：处理黎川的夜间列车邀请、沈曜的延迟语音、周棠的隐私审计、闻笙的创作片段、六人群聊或 W-17 延迟消息；建议按钮只选择意图，自由输入仍然保留。
7. 通信关系：切换沉浸模式与观测员区间模式，区分长期关系和近期通信脉冲；普通沉默不会扣关系。
8. 共同事件：填写理由并处理“绥”；五人会根据自己的经历产生不同理解，没有唯一正确答案。
9. 命运档案：保存节点或回溯。联系人权限、未读消息、承诺、关系、知识和 NPC 状态会随分支一起恢复。
10. 第一根自由的线：完成许澄结局后进入封闭织界室，为回声 000 依次建立身份、愿望、记忆、边界和世界；每一段都保留自由输入。
11. 首次创生：免费创建可编辑的“南星”和“潮汐城”，达到观测等级 Lv.8，成为织界师。
12. 织界工坊：每月可确认新建 3 位角色和 1 个世界；只有“确认创生”扣次数，草稿、编辑、首次教学和主线不扣，已有内容不会重置。
13. 回忆：事实、事件和承诺/边界可编辑；角色的关系判断与反思只能查看、置顶或删除，不能直接改写。
14. 设置：切换中英文、调整主动消息频率，并导出、导入或重置整个关系档案。

浏览器会通过 `localStorage` 自动保存体验进度。清除浏览器网站数据会删除本地进度，因此重要状态可以使用“导出关系档案”保存为 JSON。

## 当前 Demo 的实现范围

- 默认完整离线运行，不需要 API Key；可选启用服务端 Gemini + Supabase + Cloudflare 闭环；
- 中英文界面；
- 响应式手机界面与桌面演示壳；
- 17 秒停电、五处同时信号与共享的命运观测站主谜团；
- 祁安、沈曜、黎川、周棠、闻笙五位拥有独立生活、边界、知情范围和关系时间线的初始角色；
- 开场冲突故事和始终可用的自由输入；
- 角色→玩家的 11 个内部维度、独立的玩家表达信号和双方确认层；
- 关系状态只通过确认对话改变，不由好感阈值、示爱文本或吸引力自动生成；
- 共享 NPC“绥”事件及角色之间的独立关系；
- 带来源、可信度、知情人、世界和分支信息的知识与记忆；
- 可恢复的本地分支节点；
- 《第一根自由的线》、回声 000 的五条稳定线、免费首次 NPC/世界创生与 Lv.8 织界师解锁；
- 显示月相校准、3 次角色与 1 次世界确认额度的织界工坊；草稿和编辑不扣次数，已有内容永久保留；
- 带来源线、愿望、矛盾、记忆、初始关系、边界与三种连续性模式的本地角色/世界创建卡；
- EchoLink 锁屏，以及讯息、联系人、动态、关系观测和档案五个内部页面；
- 五位初始角色加绥、叶澄共七个联系人，联系方式由剧情、NPC 意愿和世界规则决定；
- 私聊、第七异常观测小组群聊、未知号码和跨世界延迟消息；
- 文字、模拟照片、模拟语音留言与通话权限状态；
- 玩家真实意图标签只供系统使用，不会直接显示给 NPC；
- 回应可靠性、主动平衡、话题深度和渠道舒适度四项近期通信脉冲；
- 异步邀请、承诺记录与后续兑现、提前说明或失约结算；
- 基于关键词、关系状态和记忆的本地模拟角色回复；单次发送后会显示对应角色头像与三点输入动画，并按角色习惯、关系连续性、沟通渠道和近期通信节奏调整模拟等待时间；
- 六种可切换故事背景；
- 根据自然语言模拟 AI 场景生成；
- 主时间线、番外和场景档案；
- 按事实、事件、承诺/边界、关系判断和反思分类的长期记忆；
- 角色自己的近期生活状态；
- 无每日任务、金币、消息额度或情感绑架设计；
- PWA 离线缓存；
- 无第三方 JavaScript 依赖。

## 验证项目

```bash
npm test
```

测试会检查核心文件、服务器/API 回退、schema v9 与 v8 至 v1 迁移、结构化事件校验、应用规则控制的剧情标记、可追溯记忆、FLUX 场景触发与缓存复用、导入导出、关系信号、同意边界和角色敏感度。

## 使用 Codex 修改

先阅读 `CODEX_START_HERE.md`。在项目根目录运行：

```bash
codex
```

Codex 会自动读取根目录的 `AGENTS.md`。项目还包含 `.codex/skills/echoloom-prototype/SKILL.md`，可在 Codex 中通过以下方式明确调用：

```text
$echoloom-prototype
```

最常用的可复制任务已经放在 `CODEX_PROMPTS.md`。
