# EchoLoom Interactive Demo

A dependency-free, locally runnable mobile prototype for a story-first, multi-character relationship simulation with reversible narrative branches.

## Run

Node.js 18+ is recommended.

```bash
npm start
```

No dependency installation is required. The local server opens `http://127.0.0.1:5173`.

Platform launchers are included:

- macOS: `run-mac.command`
- Windows: `run-windows.bat`
- Linux: `run-linux.sh`

## Test

```bash
npm test
```

## What is interactive

The prototype now opens with a brand/title sequence and a persistent visual-novel onboarding: the 17-second outage, player naming, a five-signal orbital scan, one three-character rescue, a qualitative result, EchoLink activation, first free-text contact, the formal Observatory home, and isolated branch creation. EchoLink remains a second main interface with Messages, Contacts, Moments, Bonds, and Archive tabs; story-dependent permissions; private/group/delayed threads; avatar-based typing feedback; relationship-aware reply timing; and branch-aware history. Existing relationship analysis, shared events, typed memories, world/scene generation, custom NPC creation, bilingual UI, and schema-versioned JSON export/import remain available from the five-part primary navigation and desktop feature-demo group.

Relationship dimensions are never presented as an affection score, and attraction or player wording never confirms romance, exclusivity, or consent automatically.
