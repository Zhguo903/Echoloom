# Three-character foundation — completed

The first refactor replaced the single Aren timeline with independent Qi An, Shen Yao, and Li Chuan journeys. It added character-specific stories, chats, memories, generated scenes, original artwork, schema-v2 persistence, schema-v1 archival migration, and mobile/desktop verification.

This foundation intentionally kept the relationship simulation small: six hidden dimensions, no shared campaign state, and no reversible branch graph. The active plan in `PLANS.md` extends that base into the Fate Observation Station MVP.
